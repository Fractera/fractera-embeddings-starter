# The model of this element

The files of the release `model-minilm-l12-1` of this repository are a copy, unchanged, of the ONNX export
[`Qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q`](https://huggingface.co/Qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q)
(the file `model_optimized.onnx`, here named `model.onnx`, with its tokenizer and configuration) of the model
[`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)
by Nils Reimers and Iryna Gurevych (UKP Lab, TU Darmstadt): «Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks»
(EMNLP 2019) and «Making Monolingual Sentence Embeddings Multilingual using Knowledge Distillation» (EMNLP 2020).
